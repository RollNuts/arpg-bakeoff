# Character Pattern Cards

Status: active character direction for `色喰いの王冠`.

The current product direction is
`docs/product/game-definition-color-eater-crown.md`.

Previous Threadlight, Relic Runebound, and generic solo swordfighter concepts
are retained as part-library evidence only. Do not adopt any old generated sheet
wholesale as the player character.

## Judgement Order

Before generation, modeling, rigging, or animation spend, judge in this order:

1. black silhouette at tiny size
2. third-person gameplay readability
3. grayscale value separation
4. current color state readability
5. attack, dodge, parry, color drain, color skill, hit, and death pose read
6. material identity
7. only then texture detail
