# ARPG Bakeoff

Public planning and review repo for a top-down dark fantasy ARPG / roguelite
prototype.

This repository exists to keep the next work clean:

- no inherited Unity mock implementation
- no reuse of the first-person Unreal hotel project
- no new Maya/Meshy/API spend before written gates pass
- every meaningful step happens through a pull request
- Veripsa Core can coordinate task slicing and program structure in PR comments

## Current Objective

Find the smallest path to a commercial-looking 30-second prototype:

1. readable playable hero
2. top-down combat camera
3. diagonal movement and attack flow
4. enemy density ramp
5. reward/build choice
6. screenshot and short-capture evidence

## Ground Rules

- Do not copy existing game characters, UI, logos, costumes, silhouettes, or
  palettes.
- Use market references only for quality bars, readability, pacing, and store
  presentation patterns.
- Prefer CC0/free assets before paid or API-generated assets.
- Use Maya as an inspection, cleanup, conversion, or rigging tool, not as a
  reason to spend on throwaway assets.
- Keep generated assets isolated with provenance notes.
